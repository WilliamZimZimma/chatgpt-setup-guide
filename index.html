Create your account and select Pro 100

ChatGPT Pro 100 is $100 USD per month and includes Work and Codex. Use Work for tasks that draw on your Google apps and Codex for coding and website updates.

  1. On your computer, open ChatGPT. Use your own browser profile during setup if someone else is helping you.
  2. Select Sign up. Choose Continue with Google and select your intended Google account, or follow the email sign-up flow. If you already have a ChatGPT account you want to use, sign in with its existing method.
  3. Open your profile menu and confirm the email under Settings → Account.
  4. While signed in, open ChatGPT pricing. Choose Pro 100, check the monthly total and billing details, then complete checkout. Confirm your plan in Settings.
  5. Download and install the ChatGPT desktop app for macOS or Windows. Sign in with the same account.
  6. In the desktop app, select ChatGPT in the app menu and choose Work in the mode toggle. To work on code later, switch to Codex in the app menu.

Keep your login, recovery methods, and Google approval prompts under your control. A friend can walk you through the screens while you sign in and approve access.

Connect your Google apps

Your ChatGPT sign-in and your Google app permissions are separate. For a Google-hosted mailbox, Gmail is the app to connect for email. If you also use a separate mailbox, look for its provider’s plugin and connect that mailbox separately.

  1. In ChatGPT, open Plugins in the sidebar, or go to Settings → Plugins. If your interface says Apps, open Settings → Apps.
  2. Search for Gmail. Select Install or Install plugin if shown, then Connect or Continue when prompted.
  3. On the Google account picker, choose the account that owns the mailbox, files, and calendars you want to use. Review the requested permissions before authorizing. If ChatGPT offers a combined Google setup, choose Gmail, Google Drive, and Google Calendar there. Use Select fewer apps if you want to connect fewer. Approve the requested permissions for the apps you choose.
  4. Back in ChatGPT, check each app’s connection under Settings → Plugins or Apps. For any unconnected app, search for its name, install if prompted, and follow its connection flow. Check the Google address shown on each connection.
  5. Open a fresh Work chat for each test below. Select the app from the + menu or type @ and choose it when available.

Review permissions or troubleshoot

  • In the relevant app’s settings, open Permissions where available. Always ask prompts before reads and changes. Allow read actions allows reads and prompts before changes.
  • If Google blocks a work account, ask the Google Workspace admin to review the ChatGPT/OpenAI app and required OAuth permissions. If ChatGPT says Disabled by admin, ask the ChatGPT workspace admin to check availability.
  • To remove access, open the app in Settings → Plugins or Apps, select the connected account, and choose Disconnect. Review any existing chats and saved memories separately if you want to remove them.

Upload the HTML to GitHub

This file is a standalone guide. Google authorization happens in ChatGPT. The HTML page serves the written instructions.

  1. Save a copy of this file as index.html. If you’re already viewing it in a browser, use Save Page As and choose the HTML-only format if offered.
  2. Sign in or create an account at GitHub. Open New repository.
  3. Choose the GitHub account that should own the repo. Enter a name such as chatgpt-setup-guide and choose your visibility. A private repo limits who can read the source.
  4. Enable Add README to initialize the repo, then select Create repository.
  5. On the repository’s Code tab, choose Add file → Upload files. Drop in index.html at the top level beside the README.
  6. Enter a commit message such as Add setup guide, then select Commit changes. Confirm index.html appears at the top level of the default branch.

Deploy the GitHub repo on Vercel

  1. Sign up or sign in at Vercel. Select the Vercel account or team that should own the site. Hobby is for personal, non-commercial use. Choose Pro for business use.
  2. In the dashboard, choose Add New → Project. Connect GitHub or install the Vercel GitHub app if prompted. Grant it access to the guide repository.
  3. Find chatgpt-setup-guide under Import Git Repository and select Import.
  4. Set the Framework Preset to Other. Keep the Root Directory at the repository root. In Build and Output Settings, turn on the Build Command override and leave its field empty. Leave the output directory at its default. This page requires zero environment variables.
  5. Select Deploy. Once the deployment is ready, open the project’s .vercel.app domain and test the navigation and layout.
  6. If access should be restricted, open Security → Deployment Protection and choose All Deployments under Vercel Authentication. Verify the intended access from a signed-out window. GitHub visibility and site access are configured separately.
